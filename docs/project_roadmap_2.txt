  NSE Stock Analysis Web App (AmiBroker Style) | 100% Free-Tier Stack

1. PROJECT GOAL
--------------------------------------------------------------------------------
Build a fast, free-tier web app analyzing ~2,700 NSE symbols with daily price 
data from 2000 to present (~17.5M rows) without hitting server memory limits 
or database costs.

2. CORE ARCHITECTURE
--------------------------------------------------------------------------------
• STORAGE (Cloudflare R2): 
  - Historical market data organized into 27 yearly compressed Parquet files 
    (2000.parquet through 2026.parquet) totaling ~150–200 MB.
  - Fits comfortably within R2 free limits: 10 GB storage, 1M Class A (writes), 
    and 10M Class B (reads) operations/month with $0 egress fees.

• HOSTING (Render Free Tier):
  - Serves as a lightweight web server and static host.
  - Bypasses Render's 512 MB RAM limit and ephemeral disk wipe issues because 
    all historical price data resides in Cloudflare R2 and browser memory.

• COMPUTE ENGINE (Browser Client):
  - Downloads Parquet files as ArrayBuffers into browser memory.
  - Queries data, calculates technical indicators (SMA, EMA, RSI, MACD, Bollinger 
    Bands), and executes backtests locally using DuckDB-WASM and JavaScript.

• CACHING LAYER (Browser IndexedDB / CacheStorage):
  - Past historical years (2000–2025) are static and cached permanently in 
    the user's browser IndexedDB after the first load.
  - Current year (2026.parquet) is cache-busted daily after market close.
  - Repeat backtests run with 0 R2 read operations.
