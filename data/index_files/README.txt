Drop index history CSV files here (downloaded by hand from niftyindices.com -> Reports -> Historical Data, or any file with
Date/Open/High/Low/Close columns). Name the file like "Nifty 50_Historical....csv" (the index name first) unless the file has an "Index Name" column.
Run the "Daily NSE Fetcher" workflow once: the files are stored as ^NIFTY50 etc., then moved to the folder "done".
Use this for years that NSE's daily all-indices files do not cover.
